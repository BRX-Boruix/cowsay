# cowsay

BORUIX 的 cowsay：一头会说话的 ASCII 牛，也是第三方程序开发样例。

[English](README.en.md)

## 用法

```
/volumes/BORUIX_DATA/3p/cowsay.elf hello world
```

输出：

```
/-----------------\
| hello world     |
\-----------------/
        \   ^__^
         \  (oo)\_______
            (__)\       )\/\
                ||----w |
                ||     ||
```

## 它的双重身份

一个能用的程序：把命令行参数显示在气泡里。更重要的用途是一份可抄的最小模板：只依赖 `libsys`，
导出一个 `user_main`，经真实系统调用写标准输出，不使用任何内核特权。

它**不进系统镜像**：由第三方构建流程编译后放到数据盘，用户按普通文件路径执行。内核按纯路径
解析可执行文件，不要求程序位于固定位置。

## 参数的约定

BORUIX 的进程入口不传拆分好的参数列表：

- 入口处参数个数恒为 1
- 整条命令行是同一个字符串，不含程序名
- 按空格拆词是用户程序自己的职责

所以本程序**不剥掉第一个词**——整条命令行就是要说的话。按 POSIX 习惯剥首词会把唯一的参数
吃掉，输出一个空气泡。

## 边界行为

宁可报错，也不产出与输入不符的图：

- 没有参数：打印用法到标准错误，退出码 2
- 参数超过 64 个词：如实报错，不静默丢弃
- 文本超出气泡宽度（74 字符）：如实报错，不折行
- 参数总长超过 4096 字节：如实报错，不截断

不折行的原因：气泡宽度同时是内部缓冲区的安全边界，放宽会导致框线缓冲溢出，这条判定不是美观
限制。不截断的原因：截断的气泡与用户输入不符，是伪输出。

## 构建

```bash
cargo build --release
```

产物部署到数据盘 `/3p/cowsay.elf`。

## 文件结构

```
cowsay/
├── Cargo.toml    # 包定义，仅依赖 libsys
├── build.rs      # 注入链接脚本
├── linker.ld     # 用户态段布局
└── src/
    └── main.rs   # 参数解析与气泡绘制
```
